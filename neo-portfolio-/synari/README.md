# SYNARI Smart Asset Tracker

This directory contains the first implementation artifact for SYNARI inside the portfolio workspace. The application remains **Planning / foundation milestone**: there is no running API, production database, deployment, external user base or credential in this repository.

The schema migration is designed for PostgreSQL and should be moved into the dedicated `neo-smart-asset-tracker` repository when backend implementation begins. It is not applied automatically.

Next foundation work: choose the API framework, add environment validation, create a migration runner, and add database integration tests before building UI workflows.
